# Recallly

Investigação de integração MCP própria com ChatGPT e execução local no Windows.

Estado atual: Recallly Probe 0.1.0 implementado, validado localmente e publicado em `main`. Única ferramenta: `recallly_status`, somente leitura, sem parâmetros obrigatórios ou porta de rede. Secure MCP Tunnel criado e associado; cliente oficial e perfil local preparados. A chave de runtime ainda precisa ser fornecida no terminal para ativar o túnel. Conexão pelo chat ainda não comprovada.

Não há agendador, armazenamento de lembretes, envio de e-mails, SMTP, inicialização com Windows ou interface final. A tecnologia desta prova não define a arquitetura do aplicativo completo.

Comece por [PROBE-SETUP](docs/PROBE-SETUP.md). Consulte [ambiente](docs/ENVIRONMENT.md), [viabilidade](docs/MCP-FEASIBILITY.md), [decisões](docs/DECISIONS.md) e [validação](docs/VALIDATION.md).
